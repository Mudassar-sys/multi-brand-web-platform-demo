Tracking checks on Vercel preview deployments (26 Sep 2026, Playwright, tests/specs/tracking.spec.ts)

What the Google Ads check does: it records every browser request while it opens a page with
a gclid, accepts consent, opens the form page and submits a test lead. It fails if any request
matches a Google Ads conversion or remarketing endpoint (pattern ADS_REQUEST in tests/lib/brands.ts).

State of tracking in this demo: no GTM container ID is set on the Vercel projects yet, so
no Google tag loads at all. The head-order test notes that GTM is not rendered; docs/GTM-SETUP.md
describes the container, including the exception that keeps the Ads conversion off previews.
