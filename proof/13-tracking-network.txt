Google tag network log: GTM and GA4 live, Google Ads conversion blocked on previews
Date: 26 Sep 2026. Container GTM-NGVNJ7BB (version 2), GA4 G-RJ492TFLKD, Ads Conversion ID 16832482446.

How this was captured
  Playwright Chromium: open the landing page, click Accept all, open /contact, submit a test lead
  (first name "Preview", tracking-proof@example.com), wait for the receipt, then 5 s more.
  Every request to a Google host is listed as METHOD host/path. Query strings are stripped. The
  only values shown are the event name (en), the consent state (gcs, e.g. G111 = ad_storage and
  analytics_storage granted) and which public ID the URL carries. No cookie values anywhere.
  Tags in <> mark: "carries <ID>", "GA4 hit" (GA4_HIT in tests/lib/google-tags.ts) and
  "ADS CONVERSION" (ADS_REQUEST in tests/lib/brands.ts). A request listed twice with FAILED
  net::ERR_ABORTED is Chromium aborting a beacon on navigation or a tag retry; its twin was sent.
